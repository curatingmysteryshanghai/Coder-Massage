# Coder Massage / coder马杀鸡

> AI를 기다리는 틈에, 작은 리추얼을.<br>
> *Small rituals for AI gap time.*

Coder Massage / coder马杀鸡는 AI 에이전트와 함께 무언가를 만드는 사람들을 위한, 사용자가 원할 때만 열 수 있고 집중력을 거의 들이지 않고 즐길 수 있는 작은 게임 모음입니다. 기존 설치와의 호환성을 위해 저장소의 기술 ID는 `jieya`로 유지합니다.

## 왜 만들고 있나요

바이브 코딩을 하다 보면 프롬프트를 보낸 뒤 AI 에이전트가 작업하는 동안 짧은 대기 시간이 생깁니다. 이 시간을 **AI gap time**이라고 부릅니다. 그 시간을 소셜 피드나 뉴스 스크롤로만 채울 필요는 없습니다.

업무 중 잠깐 즐기는 게임에는 몇 가지 현실적인 조건이 있습니다. 몇 초 안에 시작할 수 있고, 언제든 바로 멈출 수 있으며, 소리를 켜거나 오래 집중할 필요가 없어야 합니다. 작업으로 돌아가는 과정도 자연스러워야 합니다. 점수, 연속 기록, 피드, 필수 진행 요소가 없습니다. 목적이나 성과를 요구하지 않는 가벼운 놀이 역시 일상의 웰빙을 돕는 작은 도구가 될 수 있습니다.

우리 팀은 게임의 규칙과 화면에 더해, 사람과 AI가 함께 일하고 기다린 뒤 다시 공동의 작업으로 돌아가는 관계와 리듬도 설계합니다.

## 현재 게임

지금 설치하고 테스트할 수 있는 게임은 **[Needlewhile / 扎会儿](./games/needlewhile/)** 하나입니다.

마우스를 클릭하거나 일반 키를 누르면 실뭉치에 바늘 하나가 꽂힙니다. 아주 작은 동작이 전부입니다. AI가 작업하는 동안 잠시 손을 움직이고, 작업이 끝나면 그대로 돌아오면 됩니다. 포털은 항상 사용자가 직접 선택해 여는 방식이며, 사용자가 들어가기로 선택하기 전에는 브라우저가 열리지 않습니다.

## 앞으로의 방향

추후 컬렉션 포털은 대상 게임 중 하나를 무작위로 선택합니다. 게임 내 전환 메뉴를 사용해 다른 게임으로 이동해도 같은 AI 작업 타이머는 계속됩니다.

게임 수를 빠르게 늘리기보다 AI 대기 시간에 자연스럽게 어울리는 경험을 하나씩 확인하고 다듬어 갈 계획입니다. 새 콘셉트는 독립 패키지, 검증, 릴리스 상태를 갖추기 전까지 설치 가능한 카탈로그에 포함되지 않습니다.

```text
현재: 포털 → Needlewhile
향후: 포털 → 무작위 게임 ↔ 게임 내 전환 메뉴 ↔ 다른 게임
```

자세한 내용은 [게임 목록](./games/README.md), [아키텍처](./docs/ARCHITECTURE.md), [포털 동작 규약](./docs/PORTAL.md)을 참고하세요.

## 설치 책임

AI 어시스턴트는 사전 요구 사항 확인, 저장소 다운로드, 설치 프로그램 실행, 결과 검증을 수행할 수 있습니다. Codex Hook 승인은 소유자만 수행하는 보안 작업입니다. 소유자가 직접 `UserPromptSubmit`, `PostToolUse`, `Stop`을 검토해야 하며, 어시스턴트가 소유자를 대신해 Hook을 승인하거나 신뢰 기록을 수정해서는 안 됩니다. 정확한 절차는 [설치 및 검증 규약](./docs/INSTALLATION.md#installation-responsibilities)을 따르세요.

## 이름 안내

`Coder Massage / coder马杀鸡`는 제품명입니다. `jieya`는 저장소와 플러그인 마켓플레이스의 호환성 ID입니다. `Needlewhile / 扎会儿`는 현재 테스트 중인 첫 번째 게임의 이름이며, 기준이 되는 Codex 플러그인 ID는 `needlewhile@jieya`입니다.

## 개인정보 보호

현재 빌드는 로컬에서 실행됩니다. 컨트롤러는 임의의 접근 토큰을 사용하며 `127.0.0.1`에만 바인딩됩니다. 작업 이름은 짧고 안전한 형태로 정리해 메모리에서만 다루고, 원본 프롬프트는 디스크에 기록하지 않습니다. 전역 키보드 감시, 손쉬운 사용 권한, 분석 기능, 계정, 광고, 원격 게임 서비스도 사용하지 않습니다.
